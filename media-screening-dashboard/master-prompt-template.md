# Master prompt (rehearsal stand-in, blanks version)

This is not the real master prompt from the event organizers. It is a
plausible stand-in, written to match Mission 1's own description ("fill in
the blanks, do not change any other line") so there is something to
rehearse against before the real one arrives. Swap this file out the
moment the real prompt shows up.

Fields to fill in are marked `[LIKE_THIS]`. Nothing else in the prompt
below should change.

---

Build a single, self-contained HTML dashboard called "[DASHBOARD_TITLE]"
for [COMPANY_NAME], a wealth management firm, to screen recent media
coverage.

Use the attached sample data, which represents media mentions of
[COMPANY_NAME] over [REPORTING_PERIOD]. Each entry has a date, a headline,
a source, a country, a media type, and a sentiment (positive, neutral, or
negative).

The dashboard must include exactly these four charts:

1. A frequency chart showing the number of articles per day over the
   period.
2. A sentiment chart showing the split between positive, neutral, and
   negative coverage.
3. A chart showing coverage by country.
4. A chart showing coverage by media type.

Below the charts, include a table listing every article with its date,
headline, source, country, media type, and sentiment.

Make the country, media type, and sentiment charts clickable: clicking a
bar or segment filters the table and the other charts down to that
selection. Clicking the same element again clears the filter.

Keep it a single page with no build step and no external libraries
required to open it. Do not change anything else about this prompt.
